读写参数

字符 含义
‘r’ 读入
‘w’ 写入
‘a’ 在文件后补充
‘b’ 二进制
‘+’ 打开用于更新

二进制打开方式不需要encoding参数

eg：用二进制写入’wb'

文本光标操作#

f.tell()
# tell 方法：文件对象的 tell 方法返回整数，表示文件指针距离文件开头的字节数

f.seek(偏移光标字节数,偏移参考)
# seek方法：移动文件句柄

关于seek方法的参数：

offset 表示偏移指针的字节数
whence 表示偏移参考，默认为 0
0 表示偏移参考文件的开头，offset 必须是 >=0 的整数
1 表示偏移参考当前位置，offset 可以是负数
2 表示偏移参考文件的结尾，offset 一般是负数

csv#

csv文件简介#

  1. 纯文本文件
  2. 表格结构

以上特点决定了csv文件可以在编程软件中打开，同时也可以在表格软件中打开

  • ==分隔符（delimiter）==

    字段之间通常用 ​逗号(,)​ ​ 分隔，虽然也有可能用其他符号（如制表符、分号）作为分隔符。

  • ==转义==

    csv文件中转义符是引号（"）​

    用于：

    1. 包含特殊字符（引号，逗号（分隔符），换行符）
    2. 其中引号还要再次转义

导入csv包#

​import csv​

读取csv文件#

读取后生成字典#
with open("file.csv",'r') as f:
	result=csv.reader(f)

==reader返回的数据类型为双层列表==

也就是说：

一行为一个列表，这个列表同时也是result中的元素

因此，应用举例如下

# 2.提取某列数据: 如name这一列
with open('./tmp/test.csv', 'r') as file:
    reader = csv.reader(file)
    for row in reader:
        print(row[1])
读取后生成字典#
csv.DictReader(f,fieldnames=标题列表)

返回数据类型为元素为字典的列表

fieldnames默认为第一行元素

举个栗子

import csv

with open('./tmp/stu.csv', mode='r', newline='', encoding='utf8') as file:
    reader = csv.DictReader(file)
    for row in reader:
        row: dict = row
        print(row, row.get('ID'), row.get('学号'), row.get('班级'))

举个栗子

import csv

with open('output.csv', 'w', newline='') as csvfile:
    fieldnames = ['first_name', 'last_name']
    writer = csv.DictWriter(csvfile, fieldnames=fieldnames)

    writer.writeheader()
    writer.writerow({'first_name': 'Baked', 'last_name': 'Beans'})
    writer.writerow({'first_name': 'Lovely', 'last_name': 'Spam'})
    writer.writerow({'first_name': 'Wonderful', 'last_name': 'Spam'})
