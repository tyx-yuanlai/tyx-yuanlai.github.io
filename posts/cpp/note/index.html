NOTE#

常量成员函数是 C++ 中的一个重要概念，它表示该成员函数不会修改类的成员变量（即不会修改对象的状态）。常量成员函数的定义方式是在函数声明的末尾加上 const​ 关键字。

常量成员函数的作用#

  1. 保证不修改对象状态：

    • 在常量成员函数中，不能修改类的非 mutable​ 成员变量。
    • 如果尝试修改成员变量，编译器会报错。

  2. 允许常量对象调用：

    • 常量对象（用 const​ 修饰的对象）只能调用常量成员函数。
    • 非常量对象既可以调用常量成员函数，也可以调用非常量成员函数。

  3. 提高代码的可读性和安全性：

    • 明确告诉调用者，这个函数不会修改对象的状态。
    • 防止意外修改对象的状态。

也就是说，加上const修饰之后const类型的对象也可以调用，一般用于返回某个数值时使用

示例代码#

class MyClass {
    int value_;
public:
    MyClass(int value) : value_(value) {}

    // 常量成员函数
    int getValue() const {
        return value_; // 可以读取成员变量
    }

    // 非常量成员函数
    void setValue(int value) {
        value_ = value; // 可以修改成员变量
    }
};

int main() {
    const MyClass obj1(10); // 常量对象
    MyClass obj2(20);       // 非常量对象

    int val1 = obj1.getValue(); // 正确：常量对象可以调用常量成员函数
    // obj1.setValue(30);       // 错误：常量对象不能调用非常量成员函数

    int val2 = obj2.getValue(); // 正确：非常量对象可以调用常量成员函数
    obj2.setValue(30);          // 正确：非常量对象可以调用非常量成员函数

    return 0;
}

关键点#

  1. 常量成员函数的定义：

    • 在函数声明的末尾加上 const​，例如：

      int getValue() const { return value_; }

  2. 常量对象：

    • 用 const​ 修饰的对象是常量对象，例如：

      const MyClass obj(10);

    • 常量对象只能调用常量成员函数。

  3. 非常量对象：

    • 非常量对象可以调用常量成员函数和非常量成员函数。

  4. ​​mutable​​ 成员变量：

    • 如果某个成员变量被声明为 mutable​，即使在常量成员函数中也可以修改它。

      mutable int counter_;

总结#

常量成员函数是一种设计上的约束，用于保证函数不会修改对象的状态。它提高了代码的安全性和可读性，同时允许常量对象调用这些函数。
