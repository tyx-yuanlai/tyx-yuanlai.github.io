pair 赋值

在C++中，可以使用std::pair​将两个值组合在一起，并通过结构化绑定（C++17引入）或手动解包的方式将std::pair​的值赋值给两个变量。

方法 1：使用结构化绑定（C++17及以上）#

结构化绑定是一种简洁的方式，可以直接将std::pair​的值解包到两个变量中。

#include <iostream>
#include <utility> // for std::pair

int main() {
    std::pair<int, double> myPair = {42, 3.14};

    // 使用结构化绑定解包
    auto [firstValue, secondValue] = myPair;

    std::cout << "First: " << firstValue << ", Second: " << secondValue << std::endl;
    return 0;
}

输出：

First: 42, Second: 3.14

方法 2：手动解包#

如果你使用的是C++11或C++14，可以通过std::pair​的first​和second​成员手动解包。

#include <iostream>
#include <utility> // for std::pair

int main() {
    std::pair<int, double> myPair = {42, 3.14};

    // 手动解包
    int firstValue = myPair.first;
    double secondValue = myPair.second;

    std::cout << "First: " << firstValue << ", Second: " << secondValue << std::endl;
    return 0;
}

输出：

First: 42, Second: 3.14

方法 3：使用std::tie​（C++11及以上）#

​std::tie​可以将std::pair​的值绑定到已存在的变量。

#include <iostream>
#include <utility> // for std::pair
#include <tuple>   // for std::tie

int main() {
    std::pair<int, double> myPair = {42, 3.14};

    int firstValue;
    double secondValue;

    // 使用 std::tie 解包
    std::tie(firstValue, secondValue) = myPair;

    std::cout << "First: " << firstValue << ", Second: " << secondValue << std::endl;
    return 0;
}

输出：

First: 42, Second: 3.14

总结#

  • C++17及以上：推荐使用结构化绑定（auto [x, y] = pair;​），简洁高效。
  • C++11/C++14：可以使用std::tie​或直接访问first​和second​成员。
  • 根据代码环境和需求选择合适的方式。
