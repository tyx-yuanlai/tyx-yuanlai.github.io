R"()"#

在C++11及以上版本中，R"()"​ 是一种原始字符串字面量（Raw String Literal） 的语法，用于避免转义字符（如\n​、\t​等）的麻烦。原始字符串字面量会保留字符串中的所有字符，包括换行符和特殊符号，直到遇到结束标记为止。

基本语法#

原始字符串字面量的语法如下：

R"delimiter(raw_characters)delimiter"
  • ​delimiter​ 是一个可选的标记，用于避免字符串内容中出现与结束标记冲突的情况。
  • ​raw_characters​ 是字符串的实际内容。

如果没有特殊需求，可以省略 delimiter​，直接使用 R"(...)"​。

示例 1：基本用法#

#include <iostream>
#include <string>

int main() {
    // 使用原始字符串字面量
    std::string str = R"(Hello, World!\nThis is a "raw" string.)";

    std::cout << str << std::endl;
    return 0;
}

输出：

Hello, World!\nThis is a "raw" string.

注意：

  • 字符串中的 \n​ 不会被解释为换行符，而是直接作为字符 \​ 和 n​ 输出。
  • 双引号 "​ 也不需要转义。

示例 2：包含换行符#

原始字符串字面量可以包含换行符，换行符会直接保留在字符串中。

#include <iostream>
#include <string>

int main() {
    std::string str = R"(Line 1
Line 2
Line 3)";

    std::cout << str << std::endl;
    return 0;
}

输出：

Line 1
Line 2
Line 3

示例 3：自定义分隔符#

如果字符串内容中包含 )"​，会导致原始字符串提前结束。此时可以使用自定义分隔符。

#include <iostream>
#include <string>

int main() {
    // 使用自定义分隔符 "delim"
    std::string str = R"delim(This is a string with )" inside it.)delim";

    std::cout << str << std::endl;
    return 0;
}

输出：

This is a string with )" inside it.

示例 4：多行字符串#

原始字符串字面量非常适合定义多行字符串，例如 JSON、XML 或 SQL 查询。

#include <iostream>
#include <string>

int main() {
    std::string json = R"(
{
    "name": "Alice",
    "age": 25,
    "city": "Wonderland"
})";

    std::cout << json << std::endl;
    return 0;
}

输出：

{
    "name": "Alice",
    "age": 25,
    "city": "Wonderland"
}

总结#

  • ​R"()"​ 是 C++11 引入的原始字符串字面量语法，用于避免转义字符的麻烦。
  • 可以包含换行符和特殊符号，适合定义多行字符串或复杂文本。
  • 如果字符串内容包含 )"​，可以使用自定义分隔符，例如 R"delim(...)delim"​。
  • 原始字符串字面量在编写 JSON、XML、正则表达式或多行文本时非常有用。
