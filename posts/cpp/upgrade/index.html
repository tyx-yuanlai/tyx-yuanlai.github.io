C++11 引入了 <random>​ 库，提供了更强大、更灵活的随机数生成功能。与 rand()​ 相比，<random>​ 库具有以下优点：

  1. 更高质量的随机数。
  2. 更灵活的范围控制。
  3. 支持多种随机数分布（如均匀分布、正态分布等）。

下面是如何使用 <random>​ 库生成随机数的详细说明和示例代码。

<random>​ 库的核心组件#

  1. 随机数引擎：

    • 用于生成随机数序列。

    • 常用的引擎：

      • ​std::default_random_engine​：默认的随机数引擎。
      • ​std::mt19937​：基于梅森旋转算法的随机数引擎（高质量）。

  2. 随机数分布：

    • 用于将随机数引擎生成的随机数映射到指定的分布。

    • 常用的分布：

      • ​std::uniform_int_distribution​：均匀分布的整数。
      • ​std::uniform_real_distribution​：均匀分布的浮点数。
      • ​std::normal_distribution​：正态分布的浮点数。

  3. 种子：

    • 用于初始化随机数引擎。
    • 可以使用当前时间（std::time(0)​）作为种子，以确保每次运行程序时生成不同的随机数序列。

示例代码#

1. 生成均匀分布的整数#

#include <iostream>
#include <random>  // 包含随机数库
#include <ctime>   // 用于获取时间种子

int main() {
    // 初始化随机数引擎
    std::mt19937 rng(std::time(0));

    // 定义分布范围 [min, max]
    int min = -10;
    int max = 10;
    std::uniform_int_distribution<int> dist(min, max);

    // 生成随机数
    for (int i = 0; i < 10; ++i) {
        int randomValue = dist(rng);
        std::cout << "Random value: " << randomValue << std::endl;
    }

    return 0;
}

2. 生成均匀分布的浮点数#

#include <iostream>
#include <random>
#include <ctime>

int main() {
    // 初始化随机数引擎
    std::mt19937 rng(std::time(0));

    // 定义分布范围 [min, max)
    float min = 0.0f;
    float max = 1.0f;
    std::uniform_real_distribution<float> dist(min, max);

    // 生成随机数
    for (int i = 0; i < 10; ++i) {
        float randomValue = dist(rng);
        std::cout << "Random value: " << randomValue << std::endl;
    }

    return 0;
}

3. 生成正态分布的浮点数#

#include <iostream>
#include <random>
#include <ctime>

int main() {
    // 初始化随机数引擎
    std::mt19937 rng(std::time(0));

    // 定义正态分布（均值为 0，标准差为 1）
    std::normal_distribution<float> dist(0.0f, 1.0f);

    // 生成随机数
    for (int i = 0; i < 10; ++i) {
        float randomValue = dist(rng);
        std::cout << "Random value: " << randomValue << std::endl;
    }

    return 0;
}

总结#

  • ​<random>​ 库提供了更强大、更灵活的随机数生成功能。
  • 核心组件包括随机数引擎（如 std::mt19937​）和随机数分布（如 std::uniform_int_distribution​）。
  • 通过设置种子（如 std::time(0)​），可以确保每次运行程序时生成不同的随机数序列。
  • 可以根据需要生成均匀分布、正态分布等不同类型的随机数。

如果你需要高质量的随机数，<random>​ 库是比 rand()​ 更好的选择！
