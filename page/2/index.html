std__find

std::find 2. 使用 ​std::find​​ 算法 C++ 标准库提供了 std::find​ 算法，可以在 std::vector​ 中查找元素。 示例代码 #include <iostream> #include <vector> #include <algorithm> // 包含 std::find int main() { std::vector<int> vec = {1, 2, 3, 4, 5}; int target = 3; // 使用 std::find 查找 auto it = std::find(vec.begin(), vec.end(), target); if (it != vec.end()) { std::cout << "Found at index: " << std::distance(vec.begin(), it) << std::endl; } else { std::cout << "Not found" << std::endl; } return 0; } 输出 Found at index: 2 特点 使用标准库算法，代码简洁。 时间复杂度：O(n)​。
