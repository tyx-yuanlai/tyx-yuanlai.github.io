R"()" 在C++11及以上版本中，R"()"​ 是一种原始字符串字面量（Raw String Literal） 的语法，用于避免转义字符（如\n​、\t​等）的麻烦。原始字符串字面量会保留字符串中的所有字符，包括换行符和特殊符号，直到遇到结束标记为止。 基本语法 原始字符串字面量的语法如下： R"delimiter(raw_characters)delimiter" ​delimiter​ 是一个可选的标记，用于避免字符串内容中出现与结束标记冲突的情况。 ​raw_characters​ 是字符串的实际内容。 如果没有特殊需求，可以省略 delimiter​，直接使用 R"(...)"​。 示例 1：基本用法 #include <iostream> #include <string> int main() { // 使用原始字符串字面量 std::string str = R"(Hello, World!\nThis is a "raw" string.)"; std::cout << str << std::endl; return 0; } 输出： Hello, World!\nThis is a "raw" string. 注意： 字符串中的 \n​ 不会被解释为换行符，而是直接作为字符 \​ 和 n​ 输出。 双引号 "​ 也不需要转义。 示例 2：包含换行符 原始字符串字面量可以包含换行符，换行符会直接保留在字符串中。 #include <iostream> #include <string> int main() { std::string str = R"(Line 1 Line 2 Line 3)"; std::cout << str << std::endl; return 0; } 输出： ...
